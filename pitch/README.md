## Claim discipline

The February 2022 event is a motivating example, not a claim that a real-time warning would certainly have prevented the loss. State what was observed, distinguish it from our modeling, cite sources, and avoid unverified cost or market-size claims. Operator data and the L-12 batch are fictional demo fixtures. The dashboard records human decisions but does not command spacecraft.
